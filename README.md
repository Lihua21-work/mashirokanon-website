# 眞白花音粉丝站

## 版本说明
**当前版本：v0.1.4**
为眞白花音（帕清姬）打造的轻量化、高颜值个人粉丝站点，持续迭代优化中。

### v0.1.4 更新日志 (2026.08.01)
- 动态提醒：新增直播间（21402309）实时开播状态监控看板与一键跳转功能
- 云端代理：接入 Serverless API 与 Wbi 加密签名技术，实现 B 站动态全自动实时获取
- 逻辑重构：彻底清理写死假数据，页面优化为单次+手动刷新机制，限定显示最新的 5 条动态

### v0.1.3 更新日志 (2026.07.26)
- 视觉焕新：全站引入现代化 CSS 变量与设计规范，支持精致卡片阴影、悬浮微交互与毛玻璃视觉效果
- 新增栏目：上线「小游戏」互动区与「动态提醒」通知页，补充路由配置并支持页面动态标题
- 轮播升级：优化轮播图支持透明背景形象展图，改进移动端手势滑动响应
- 页面重构：全面重构首页、个人档案、经典语录、作品展示及关于本站，提升移动端响应式体验
- 架构优化：完善 Pinia 状态管理逻辑与 Axios 请求拦截规范，增加路由切换自动置顶恢复

### v0.1.2 更新日志
- 核心修复：解决移动端轮播图无法左右滑动的问题，新增原生触摸事件兼容方案
- 路径修复：修正打包后图片加载失败问题，统一使用Vite标准资源路径写法
- 导航优化：「代表作品」更名为「作品」，永久移除「音视频下载」栏目及相关文件/路由
- 菜单优化：移动端汉堡菜单自适应宽度优化，文字居中对齐，交互更清爽
- 体验优化：轮播图手机端纯滑动交互优化，无箭头模式更符合移动端使用习惯

### v0.1.1 更新日志
- 导航栏优化：移除自动折叠，新增「音视频下载」「小游戏」「动态提醒」栏目，「关于本站」直接平铺
- 手机端交互：汉堡菜单改为导航栏下方下拉式，抽屉宽度适配
- 轮播体验：手机端隐藏箭头，纯手指左右滑动切换上一张/下一张
- 按钮布局：手机端「查看更多资料」「B站主页」「进入直播间」三按钮同一行紧凑显示

### v0.1.0 更新日志
- 清理冗余内容：移除作品页多余标注、视频跳转按钮，精简页面结构
- 完善作品展示：调整代表作品页歌曲排序，优化封面图片展示，修复加载问题
- 修正文本细节：统一页面文案，修正歌曲名等内容，优化可读性
- 为后续内容做好准备

## 技术栈
- 前端框架：Vue 3 + `<script setup>`
- 构建工具：Vite
- 部署平台：Netlify（国内直连、永久免费）
- 版本管理：Git

---

## 本地开发
```bash
# 克隆项目
git clone https://github.com/Lihua21-work/mashirokanon-website.git

# 进入项目目录
cd mashirokanon-website

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
